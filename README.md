# MOON's Reading Room 📚

MOON의 책장·추천 서가·구매도서를 한 화면에서 보는 작은 독서 기록 웹앱입니다.
정적 파일만으로 동작하며, 기록(읽을래요 · 다 읽었어요 · 👍 좋음/🙂 보통/😕 별로 · 한줄 감상)은
브라우저의 `localStorage`에 저장됩니다.

## 화면

- **📚 MOON의 책장** — 오늘/이번 달/올해 읽은 책 수, 오늘 읽을 책, 읽은 책 서재, 도서관 대출·예약 현황
  - 읽은 책 카드는 `👍 좋음`·`🙂 보통`·`😕 별로`만 달려 있고, `수정` 버튼은 없습니다. 카드를 누르면 상세 시트가 열려 거기서 감상 수정·기록 삭제를 합니다.
- **✨ 추천 서가** — 초등 3~4학년 권장 도서 52권, 제목·저자·출판사 검색, 출처·분야·도서관 필터, 정렬
  - **💖 취향 맞춤** — 읽은 책에 `👍 좋음`(또는 `🙂 보통`)을 주면, 그 책과 분야·태그·시리즈·작가가
    비슷한 책을 `data/similar_pool.json`에서 골라 추천 서가 위에 따로 보여 줍니다.
    카드마다 `💖 취향 맞춤` 배지와 이유(`👍 좋음 · '구덩이'와 비슷한 성장 책`)가 붙고,
    `💖 내 별점 맞춤` 버튼으로 그것만 모아 볼 수 있습니다(기본 52권 목록은 그대로).
- **🏛️ 대출도서** — 광진구립도서관 계정 2개의 지금 대출·예약 6권과 **2026년에 빌려 반납한 78권**.
  `대출·예약 중` / `2026년 반납완료` / `전체` 알약 필터와 회원(회원 1·2) 필터, 반납일순·제목순·최근 대출순 정렬.
  반납완료 카드는 `대출 2026.10.26 → 반납 2026.10.30`처럼 기간을 보여 주고, 카드에서 바로
  `👍 좋음`·`🙂 보통`·`😕 별로`를 누르면 그 자리에서 '다 읽은 책'으로 저장되며 취향 맞춤 추천의 기준이 됩니다.
- **🛍️ 구매도서** — 예스24·알라딘에서 산 어린이·동화·원서 19권, 구매처 배지·구매일·상태, 검색·필터·정렬
- **책 상세 시트** — 맨 위에서 `👍 좋음`·`🙂 보통`·`😕 별로`를 한 번 누르면 그 자리에서 '다 읽은 책'으로 저장됩니다(추가 저장 버튼 없음). 아래에 추천 출처와 이유(구매도서는 구매 정보), 단골 도서관·광진구립도서관 소장 정보, 한줄 감상(다 읽은 책은 적고 나면 자동 저장)
- **3단계 평가 = 원터치 저장** — `👍 좋음` · `🙂 보통` · `😕 별로` 중 하나만 누르면 `다 읽었어요`와 평가가 함께 저장됩니다(예전 5단계 별점은 4·5점을 `좋음`으로 정리).
  같은 버튼을 한 번 더 누르면 평가만 지워지고, 책은 읽은 책으로 남습니다. 책장·구매도서·대출도서 카드에서도 바로 누를 수 있습니다.
- **＋ 직접 책 기록하기** — ISBN 바코드 스캔 또는 직접 입력
- **🌐 도서관 서버 (서울온)** — 서울온 앱 시설간편가입이 확인된 **14개 구** 구립도서관 목록과 전자도서관 링크.
  - `서울온 가입 가능`(14곳)은 도서관 누리집에 **서울온 시설간편가입** 안내가 확인된 곳입니다. 서울온 앱 → 시설카드 추가 →
    도서관 검색 → 통합 시설카드 추가로 **서울 거주 확인만** 하면 방문 없이 모바일 대출회원증이 나옵니다.
  - 서울온 가입이 안 되거나 안내를 확인하지 못한 구(중구·용산·성동·성북·강북·구로·금천·영등포·동작·관악·송파)와
    서울온이 아닌 서울도서관은 목록에서 뺐습니다.
  - 책 제목을 넣으면 소장·대출을 확인하는 링크가 그 제목으로 채워집니다(통합검색 주소가 확인된 광진·마포는 바로 검색 결과로,
    나머지는 도서관 홈페이지로). 카드마다 `🏠 도서관 홈페이지` · `🌐 서울온 가입 안내` · `📱 전자책` 링크가 있습니다.
  - **📱 전자책(전자도서관)** — 광진구립 전자도서관(소장형 교보문고 전자도서관, 대출 7권·15일)과 구독형(부커스, 월 5권),
    그리고 전자도서관 주소가 확인된 구립도서관 8곳 링크. 전자책은 정회원 로그인이 필요해 앱 안에서 목록을 직접 조회하지는 않습니다.
- **📱 전자책 검색 · 바로 대출** — 책 상세 시트 아래에서 광진구립 전자도서관·구독형 전자책·이용안내로 바로 가고,
  다른 구립도서관 전자도서관도 열 수 있습니다.
- **🌐 다른 서울시 구립도서관(서울온)에서 찾기** — 상세 시트에서 그 책 제목으로 서울온 가입이 확인된 14개 구 구립도서관을 바로 찾아봅니다.
- **🗑 목록에서 삭제 · 되돌리기** — 삭제는 목록 카드가 아니라 **책을 눌러 연 상세 시트**의 `🗑 목록에서 삭제`(구매·대출) · `🗑 기록 삭제`(책장)에서 합니다. 누르면
  그 책이 목록에서 바로 빠지고 탭 배지·요약·필터 숫자가 함께 줄어듭니다. 숨김은 `localStorage`에 남아 새로고침해도 유지되고,
  탭 위의 `🗑 목록에서 지운 책 N권 [되돌리기]`(지운 책이 있을 때만 보임)나 토스트의 `실행 취소`로 언제든 되돌릴 수 있습니다.
  목록에서만 감추므로 이미 남긴 읽은 기록·평가는 그대로입니다.

## 실행

정적 호스팅(GitHub Pages)에서는 그대로 열립니다. 도서관 대출·예약 현황은
확인해 둔 시점의 스냅숏(`data/accounts_status.json`)을 보여 주고, 실시간 갱신은
Pickle에 요청하면 확인해 반영합니다. 실시간 대출 조회·계정 연동을 직접 쓰려면
백엔드(`server.py`)가 필요하며, 이 저장소에는 포함되어 있지 않습니다.

## 구성

```
index.html      화면 구조
styles.css      스타일
app.js          동작 (기록 저장, 검색·필터, 상세 시트, 상호대차 링크)
data/books.json 추천 서가 도서 목록 (서지 정보·표지 URL)
data/similar_pool.json 취향 맞춤 추천 후보 29권 (독서로 조회로 ISBN·표지 검증)
data/purchased_books.json 구매도서 목록 (어린이·동화·원서, 주문번호·개인정보 제외)
data/accounts_status.json 도서관 대출·예약 현황 + 2026년 대출이력 78건 스냅숏 (로그인 ID·실명은 가림)
```

로그인 아이디·실명·주문번호는 이 저장소에 포함되어 있지 않습니다.
