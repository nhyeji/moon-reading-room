# MOON's Reading Room 📚

MOON의 책장·추천 서가·구매도서를 한 화면에서 보는 작은 독서 기록 웹앱입니다.
정적 파일만으로 동작하며, 기록(읽을래요 · 다 읽었어요 · 별점 · 한줄 감상)은
브라우저의 `localStorage`에 저장됩니다.

## 화면

- **📚 MOON의 책장** — 오늘/이번 달/올해 읽은 책 수, 오늘 읽을 책, 읽은 책 서재, 도서관 대출·예약 현황
- **✨ 추천 서가** — 초등 3~4학년 권장 도서 52권, 제목·저자·출판사 검색, 출처·분야·도서관 필터, 정렬
- **🛍️ 구매도서** — 예스24·알라딘에서 산 어린이·동화·원서 19권, 구매처 배지·구매일·상태, 검색·필터·정렬
- **책 상세 시트** — 추천 출처와 이유(구매도서는 구매 정보), 단골 도서관·광진구립도서관 소장 정보, 별점과 한줄 감상
- **＋ 직접 책 기록하기** — ISBN 바코드 스캔 또는 직접 입력

## 실행

정적 호스팅(GitHub Pages)에서는 그대로 열립니다. 도서관 대출·예약 현황은
확인해 둔 시점의 스냅숏(`data/accounts_status.json`)을 보여 주고, 실시간 갱신은
Pickle에 요청하면 확인해 반영합니다. 실시간 대출 조회·계정 연동을 직접 쓰려면
백엔드(`server.py`)가 필요하며, 이 저장소에는 포함되어 있지 않습니다.

## 구성

```
index.html      화면 구조
styles.css      스타일
app.js          동작 (기록 저장, 검색·필터, 상세 시트, 상호대차 링크)
data/books.json 추천 서가 도서 목록 (서지 정보·표지 URL)
data/purchased_books.json 구매도서 목록 (어린이·동화·원서, 주문번호·개인정보 제외)
data/accounts_status.json 도서관 대출·예약 현황 스냅숏 (로그인 ID·실명은 가림)
```

로그인 아이디·실명·주문번호는 이 저장소에 포함되어 있지 않습니다.
